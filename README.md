# Amit Awad Portfolio

Cinematic, recruiter-first personal portfolio built with Next.js, React, TypeScript, and a static-exportable architecture.

## Portfolio

The portfolio presents Amit Awad across multiple areas:

- About
- Engineering
- Projects
- Project case studies
- Experience
- Entrepreneurship
- Dharmaverse
- Resume
- Contact

## Features

- WebGL hero visual using React Three Fiber and Three.js.
- GSAP-based interaction and scroll effects.
- Responsive layouts for desktop and mobile.
- Reduced-motion considerations.
- Project case studies with source-backed evidence where available.
- Original résumé PDF preserved at `apps/web/public/Amit_Awad_Resume.pdf`.
- Static sitemap and robots metadata.
- Web manifest.
- Custom 404 page.
- GitHub Pages-compatible static export configuration.

## Tech Stack

- Next.js 15
- React 19
- TypeScript
- pnpm
- Three.js
- React Three Fiber
- Drei
- GSAP
- CSS
